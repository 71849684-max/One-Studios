# Migraciones Supabase

Este directorio recibirá únicamente migraciones nuevas, numeradas e inmutables.

Formato:

```text
YYYYMMDDHHMM_descripcion.sql
```

Los SQL históricos de la raíz aún no forman una secuencia reproducible y no deben copiarse aquí sin reconciliar primero el estado real de Supabase.
